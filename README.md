# Netflix-Statistics-Dashboard
An interactive Tableau dashboard analyzing Netflix content, including movies and TV shows, genres, ratings, release trends, country-wise distribution, and content insights.

📊 Dashboard Features & Visualizations

The dashboard explores the following aspects of Netflix's content library:
1. Content Overview: Total Movies and TV Shows available in the dataset.
2. Movies vs TV Shows: Comparison of content distribution by type.
3. Content Over Time: Analysis of titles released across different years.
4. Geographical Distribution: Country-wise distribution of Netflix content.
5. Genre Analysis: Exploration of the most common genres and categories.
6. Ratings Analysis: Distribution of content across different audience ratings.
7. Interactive Filters: Dynamic exploration using available filters such as content type, release year, country, and rating.
